# Fundamentos-de-Bases-de-datos

Este proyecto consiste en el diseño e implementación de una base de datos relacional en MySQL para gestionar los eventos científicos (conferencias, seminarios, talleres, etc.) de la Universidad Carlos III de Madrid (UC3M). El trabajo corresponde a la práctica de la asignatura "Fundamentos de Bases de Datos".   

El desarrollo del ejercicio exige completar diferentes fases que se ven reflejadas en los archivos del repositorio:

Diseño Lógico: Creación del grafo relacional (esquema de la base de datos) basado en las reglas de negocio y requisitos semánticos del sistema.   

Creación de la Base de Datos (CreateBD.sql): Script de definición de datos (DDL) que incluye la creación de todas las tablas, la especificación de tipos de datos, validaciones y la definición de claves primarias y ajenas manteniendo la integridad referencial. 

Inserción de Datos (InsertBD.sql): Script de manipulación de datos (DML) que utiliza sentencias INSERT INTO para poblar las tablas con registros de prueba, con el objetivo de verificar la estructura y preparar el entorno para las consultas.   

Consultas SQL (ConsultasBD.sql): Script que contiene la resolución de 10 consultas específicas para extraer información de la base de datos (por ejemplo, buscar el evento con mayor financiación, contar eventos por centro o listar investigadores agrupados por departamento).
